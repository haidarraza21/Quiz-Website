# Quiz Website

This project is a quiz-based web application that allows users to explore various topics, take quizzes, and contact the administrator for more information. The project is built using HTML, CSS, and JavaScript.

## Features

- **Responsive Navigation Bar**: Includes links to the Home, Topics, and About sections.
- **Sticky Navbar**: The navigation bar remains fixed at the top of the page when scrolling.
- **Interactive Contact Section**: Users can fill out a form to contact the project owner.
- **Footer**: Includes social media links and a special thanks section.

## Technologies Used

- **HTML5**: For structuring the web pages.
- **CSS3**: For styling the web pages.
- **JavaScript**: For adding interactivity, including scrolling and sticky navbar functionality.
- **Google Fonts**: For material icons.
- **Font Awesome**: For social media icons.

## Project Structure

- `index.html`: Main page containing the home, navigation bar, and footer sections.
- `1topics.html`: A page dedicated to quiz topics.
- `contact.css`: Styles for the contact form.
- `front_css.css`: Main stylesheet for the front-end.
- `images/`: Directory containing images used on the website.

## How to Run

1. Clone the repository.
2. Open `index.html` in your preferred web browser.
